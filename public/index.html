System Architecture & MILP Mathematical Model

Mathematical Formulation

Objective: Minimize Total Operating Costs = Production Costs + Multimodal Freight Costs (Rail/Road) + Inventory Holding Costs + Safety Stock Violation Penalties + Unmet Demand Penalties.

Constraints: Production Capacity Bounds, IU Inventory Conservation Balance, GU Demand & Receipt Inventory Conservation, Soft Safety Stock Shortfall Slack.

Technical Stack

  • • Frontend: Plotly.js, Tailwind CSS, Async Fetch API
  • • Deployment: Vercel Serverless Functions + Static Assets
